动机

为什么不用全相干，而采用半相干？

因为全相干所搜，比如搜索一年的信号，所需的计算量远超地球现有总算力。半相干搜索将总观测时长TobsT_\text{obs}Tobs​分割成N=Tobs/TcohN = T_\text{obs}/T_\text{coh}N=Tobs​/Tcoh​份，其中TcohT_\text{coh}Tcoh​为相干时长，也就是每一个片段的时长。常用Tcoh=1800 s=30 minT_\text{coh} = 1800\,\mathrm{s} = 30 \,\mathrm{min}Tcoh​=1800s=30min。

将全相干“降级”为半相干会导致灵敏度[^1]降低N1/4N^{1/4}N1/4，但是会大大降低计算量。这是一种tradeoff，且收益巨大。

另外，长时间的真实信号是“不完美的、会漂移[^2]的”。全相干搜索很容易受频率漂移的影响，半相干反而能提高漂移信号的探测能力。所以有时及时允许更长的TcohT_\text{coh}Tcoh​，人们也常常选择较短时段。

[^1]: 灵敏度指的是能探测到的最弱信号的应变幅度h0h_0h0​，也就是探测阈值。灵敏度越好，h0h_0h0​越小 。

[^2]: 中子星自转频率的漂移大致有三个主要来源：(1) Glitch（自转突变）[^3] (2)Timing noise（计时噪声） (3)吸积力矩涨落。

[^3]: 中子星glitch与LIGO的glitch并非同一概念。By the way，探测器的glitch对CW的影响较弱，对CBC影响较强。前者是长时间准单色信号，glitch会在长时积分中基本被抹平，后者是秒级短信号，glitch很容易被误判为CBC并合。CW需要格外注意的是持续存在的窄带噪声线（spectral lines），例如60 Hz60 \,\mathrm{Hz}60Hz的市电及其谐波、悬丝的小提琴模式，因为这些噪声是长期存在的单频结构，与CW信号特征极其相似，容易误判。

Signal model

如果要对距离很近的源观测很长时间的话，需要注意两个修正：(1) 波前能否继续被当做平面波，通过波前曲率可以直接得知波源距离；(2) 自行（proper motion），即天体垂直于视线方向的角运动，因为源在天空中的方向n^\hat{n}n^如果是缓慢变化的，那么多普勒修正v⃗⋅n^/c\vec{v}\cdot \hat{n} / cv⋅n^/c里n^\hat{n}n^就不是常数了。目前，这两种效应都没有被考虑，因为大家所采用的相干时长一般是30 min30 \,\mathrm{min}30min，比较短，这两种还没来得及累积到可观量级，所以不需要修正。

Broad approaches in CW searches

Fully coherent methods

为了便于讨论，假设简答情形，玩具模型，信号频率fsigf_\text{sig}fsig​是整数倍的1/Tobs1/T_\text{obs}1/Tobs​。

DFT：
[
\begin{equation}
\tilde{D}i = \sum^{N-1}{j=0}d_j e^{-i2\pi j i / N}
\end{equation}

Semi-coherent methods

半相干方法牺牲了对不同片段之间的相位连续性的限制，因此比全相干方法灵敏度更差，但是对单个片段的分析更灵敏。
