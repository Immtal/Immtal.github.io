在做线性拟合时，应根据误差大小来决定哪个变量放在 x 轴上，误差小的应作为自变量。因为使用这种标准拟合，等价于默认假设 x 方向的误差可以忽略不计。即，如果 x 的不确定度远小于 y，那就必须拟合 y=f(x)y = f(x)y=f(x)，反之亦然。而****不应该**根据“物理意义”来决定谁是自变量（此即“自变量谬误”）。如果两个变量的不确定性都不可忽略，且相当接近，那么标准线性拟合就不再适用。

我们得到MCMC的结果后，通常使用中位数 ±\pm± 68%68\%68% 区间，而不是均值 ±\pm± 标准差，因为后验往往是非高斯的。

误报率（FAR）

非常好，这是引力波数据分析中的核心问题之一。误报率（False Alarm Rate, FAR） 是衡量一个候选事件是否可能为真实引力波信号的重要统计指标。下面我为你分三层解释：

✅ 一、什么是“误报率”？

误报率（FAR）定义为：

在不包含真实引力波信号的情况下，仪器噪声自发产生一个与目标信号“看起来很像”的事件的频率。

单位通常是 “每年一次”、“每百年一次”，即：

  • FAR = 1/year：表示在纯噪声中，每年可能出现一次“假信号”；
  • FAR = 1/100 years：表示每百年可能才有一次假信号通过这个统计检验门槛。

✅ 二、能不能定量计算？当然可以！FAR 是通过“背景实验”定量估计的。

计算思路如下：

  1. 背景构造（Time Slides）：

    • 将两台 LIGO 探测器之间的数据人为地错开（比如相差几秒），远大于光在两个站之间传播的最大时间（约 10 毫秒），这样可以保证真实天体信号不会同时出现。
    • 这组数据只包含噪声。

  2. 重复分析：

    • 用和真实数据一模一样的算法去搜索这些“错开时间”的数据对。
    • 记录在这些背景数据中出现的“事件”的信噪比或统计量。

  3. 统计累积：

    • 假设你做了 1 万组这样的背景时间滑移，总共模拟了相当于 1 万年长度的背景数据。

    • 如果某个统计量阈值以上你发现了 100 个假信号，那么：

      FAR=10010000 years=0.01 events/year\text{FAR} = \frac{100}{10000\,\text{years}} = 0.01\,\text{events/year} FAR=10000years100​=0.01events/year

✅ 三、如何使用 FAR 来评估一个候选事件的显著性？

  1. 比较你要研究的候选事件的信号强度（比如信噪比）与背景中所有事件的信噪比分布；
  2. 如果这个候选事件比几乎所有背景事件都显著，则它的 FAR 会非常低（比如 < 1/1000 years）；
  3. 通常，我们将 FAR 小于 1/100 年 视为“显著候选事件”；
  4. GW150914 的 FAR 小于 1/203,000 years1 / 203,000\, \text{years}1/203,000years，显著性超过 5σ5\sigma5σ。

✅ 总结公式：

如果在 TbgT_\text{bg}Tbg​ 年的背景数据中发现了 NbgN_\text{bg}Nbg​ 个假事件高于你要检验的统计量阈值：

FAR=NbgTbg\text{FAR} = \frac{N_\text{bg}}{T_\text{bg}} FAR=Tbg​Nbg​​

你在上文中介绍了背景实验定量计算FAR，那么你在这里说的真实引力波事件的FAR是怎么算的呢？

非常好的追问！下面我详细解释 “一个真实引力波候选事件的 FAR 是如何计算出来的”，这其实是刚才背景实验逻辑的直接应用，但你问得很精确 —— 重点是“怎么把背景实验结果应用到真实事件上”。

✅ 1. 回顾背景实验的作用

我们通过大量“时间滑移”的背景实验，构造出一个只包含噪声的事件分布，这个分布告诉我们：

在纯噪声情况下，不同信噪比（SNR）或统计量值下，事件出现的概率是多少。

✅ 2. 真实事件的 FAR 怎么算？

现在，我们在未经时间滑移的真实数据中，发现了一个候选事件，其信号强度（例如信噪比 SNR 或更复杂的统计量）是某个数值，比如 ρ=24\rho = 24ρ=24。

我们就去看，在 所有背景实验中，有多少个事件的信噪比 超过 ρ=24\rho = 24ρ=24。

假设：

  • 背景实验总时长为 Tbg=105T_\text{bg} = 10^5Tbg​=105 年；
  • 在这些背景数据中，只有 1 个事件的统计量大于等于 24。

那么我们说：

FAR=1105 years=1 event per 100,000 years\text{FAR} = \frac{1}{10^5\,\text{years}} = 1 \text{ event per } 100,000 \text{ years} FAR=105years1​=1 event per 100,000 years

这就是这个真实事件的误报率。

✅ 3. 用于 GW150914 的例子

以 GW150914 为例：

  • LIGO/Virgo 做了大量时间滑移背景实验（比如覆盖 Tbg≈203,000T_\text{bg} \approx 203,000Tbg​≈203,000 年）；
  • 发现没有任何一个事件能达到 GW150914 的统计量水平；
  • 所以它的 FAR < 1 / 203,000 years；
  • 相当于“如果这个事件是噪声造成的，我们需要等上 20 万年才可能看到一次这样强的假信号”。

✅ 4. 总结为流程：

步骤 内容
① 在真实数据中找到候选事件，记录其统计量（如 SNR）
② 在背景实验中统计有多少个事件超过该统计量
③ 用背景总时长除以该事件数量，得出 FAR
④ FAR 越小，说明此事件越不可能是噪声，越有可能为真实引力波
